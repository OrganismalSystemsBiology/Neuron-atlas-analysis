Extended Data Fig. 23c,d - Cell-count-based neuronal quantification and required-sample-size estimation¶

  • ED23c: Normalized NeuN+ cell counts in major brain regions at 9 months, WT vs AppNL-G-F (whole-brain analysis), normalized to the WT average; isocortex and OLF (the regions analyzed by Western blot in panel b) highlighted. Statistics: generalized linear model with Benjamini-Hochberg correction.
  • ED23d: Simulation of the required total sample size to detect a given absolute difference between two groups, based on a two-sample t-test power analysis (power = 0.90, alpha = 0.05) assuming a coefficient of variation (CV) of 0.2.

ED23a (immunoblots) and ED23b (Western-blot quantification) are wet-lab/image panels. Figures preserved from the original run; Japanese stripped; verbose logs removed.

import numpy as np
import matplotlib.pyplot as plt
from scipy.stats import norm

# ----- Inputs -----
CV    = 0.20 * 2
alpha = 0.05
power = 0.90
deltas = np.arange(0.05, 0.60, 0.05)

# ----- Two-sample t-test sample size formula -----
Z_alpha = norm.ppf(1 - alpha/2)
Z_beta  = norm.ppf(power)
effect_d = deltas / CV
n_per_group = 2 * (Z_alpha + Z_beta)**2 / (effect_d**2)

#
n_total = 2 * n_per_group
n_int = np.rint(n_total).astype(int)

# ----- Styling -----
plt.rcParams['font.family'] = 'Arial'
plt.rcParams['font.size']   = 20

fig, ax = plt.subplots(figsize=(8, 7))

# Curve
ax.plot(deltas, n_total, marker='o', markersize=8, linewidth=2.5, color='darkcyan')

#
pad = max(n_total)*0.03
for d, n_float, n_lbl in zip(deltas, n_total, n_int):
    ax.text(d, n_float + pad, f"{n_lbl}", ha='center', va='bottom', color='darkcyan')

#
#for y, style in [(10, (0,(6,3))), (20, (0,(4,3))), (40, (0,(2,3)))]:
for y, style in [(10, (0,(6,3)))]:
    ax.axhline(y=y, color='gray', linestyle=style, linewidth=1.5, alpha=0.6)

# Labels
ax.set_xlabel("Target absolute difference for detection", fontsize=20)
ax.set_ylabel("Required total sample size", fontsize=20)

# Limits & clean axes
ax.set_xlim(deltas.min()-0.01, deltas.max()+0.01)
ax.set_ylim(0, max(n_total)*1.12)
ax.spines['top'].set_visible(False)
ax.spines['right'].set_visible(False)


plt.tight_layout()
